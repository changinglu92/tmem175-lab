# 帕金森诊疗中心 · 课堂互动站（第一版预览）

高三一轮复习公开课《基因的表达》中，学生用平板亲手操作的部分。教师投屏仍以课件为主。站点是静态页，不含登录，不含 App，不必构建，以后可直接放到 GitHub Pages，二维码路径可保持不变。

**本站不是整节课的 3D 化，也不仿制 WeduLab。** 题、过渡语、资料卡读图、对比填表、开放探究书写和真题留在 PPT 与任务卡上，站内不再做第二套。

## 如何本地打开预览

推荐用本地静态服务（涉及 ES 无关，主要为了路径与后续接口一致）：

```bash
cd tmem175-lab
python3 -m http.server 8765
```

浏览器打开：<http://127.0.0.1:8765/>

也可以直接用浏览器打开 `index.html`。三维模块依赖同目录下的 `js/vendor/three.min.js`，不需要外网。

当前预览默认全部解锁，方便通看全部模块。课上请用教师面板「恢复课上默认」，改回只讲到「诊断归因」，再按进度解锁。

## 教师解锁

课上按阶段解锁，课后可全部解锁。第一版**不做全班强制翻页同步**，状态只记在这台平板的浏览器里。

打开教师面板（界面刻意放得很不起眼）：

- 长按顶栏左侧的 ▲，或长按标题「帕金森诊疗中心」，或长按屏幕左下角，约 1.2 秒
- 口令只通过一对一发给授课教师，不写在本仓库或公开说明里

面板可做的事：

- 把「当前讲到」设为某一段：该段及之前解锁，之后锁定
- 专项解锁：溶酶体异常对照、参考模型、诊断标准示意
- 「全部解锁（课后）」：五个阶段和专项全部打开
- 「恢复课上默认」：回到只讲到诊断归因

请不要把口令写在学生可见的课件首页上，也不要把 API key 写进本仓库。

## 科学示意与禁忌

- 所有序列、模型、3D 均标明 **教学示意**。诊断只用第 **38–42 位密码子** 的示意片段，不是 TMEM175 全长。
- 三人对照与课件资料卡 2 一致：
  - 正常人：`GAC UUC GCC GAC GUG`（天冬氨酸—苯丙氨酸—丙氨酸—天冬氨酸—缬氨酸）
  - 患者甲：第 41 位 `GAC→GCC`，天冬氨酸→丙氨酸，错义
  - 患者乙：第 38 位 `GAC→GAU`，氨基酸不变（`GAC` 与 `GAU` 都编码天冬氨酸，简并性）
- **严禁**把真实变异 M393T（Met→Thr，ATG→ACG）或全长序列写进本站，以免和课件冲突。
- 宏观路径必须是：帕金森老人（片头端茶杯的手的静帧）→ 神经系统 → 神经元 → 溶酶体 → 图 8。**不走「皮肤→皮肤细胞」**。表型和病理在神经元。
- 图 8 立体对照：
  - 膜上两种蛋白必须区分：**V-ATPase 是氢泵**（水解 ATP，把 H⁺ 泵入）；**TMEM175 是通道**（把多余 H⁺ 漏出，不是第二种泵）
  - 腔内有水解酶（「消化车间」）、H⁺ 和 pH
  - 正常：腔内 pH **约 4.6**（范围 4.5–5.0 仅在说明里一笔带过），细胞质 ≈ 7.2
  - 异常：TMEM175 减弱，H⁺ 出不去，泵仍在泵入，pH &lt; 4.6，水解酶活性下降，α-突触核蛋白更难降解
  - 教学顺序：**先看、再问、最后才切换**。默认只展示正常溶酶体。界面列出教师要问的问题，可先猜 pH / 酶活性，再拖因果卡。异常对照必须由教师口令 / 教师面板解锁后才能切换
  - 不要提前弹出「所以导致帕金森」
- **TMEM175 是风险因子**。不要写「有替换就一定会得帕金森」，也不要把融媒体对照理解成「改一个碱基就手抖」。意象是：清理是否受阻、风险是否升高。
- 拖卡文案与课件一致，不另起竞争模型。参考模型（含折叠/定位、41 位 GAC→GCC、Asp→Ala、H⁺ 不能运出 pH&lt;4.6、多巴胺能神经元受损等更细写法）按教师口令对照，仍以课件现有卡为准。

## 课堂提问框

- 只追问本课缺的环节，不直接给标准答案，更不是讲课聊天机器人。
- 学生若过度推断（「有替换就会手抖 / 一定会发病」），只追问中间缺失的环节。
- 个人就医建议一律标为超出范围。
- **没有 API key 也能用**：内置规则式追问。若学校有兼容 OpenAI Chat Completions 的接口，可复制 `js/config.example.js` 为 `js/config.js` 后填写。`js/config.js` 已写入 `.gitignore`，**API key 不得提交到仓库，也不得写进页面源码。** 接口失败时自动退回规则底。

路由使用 hash，部署到 GitHub Pages 后地址形如：

- `/#/home` 入项
- `/#/diagnose` 诊断配对
- `/#/journey` 全景
- `/#/lysosome` 图 8
- `/#/model` 拖卡
- `/#/design` 开放设计（治疗思路）
- 旧地址 `/#/show` 会自动转到开放设计

改文件名或目录会导致二维码失效，请保持上述结构。

## 第一版有意简化的地方

- 没有全班同步翻页或教师端遥控全班屏幕
- 提问框默认走规则式追问；接上 API 也仍然只追问、不给标准答案
- 3D 是轻量教学示意（可旋转、可切面、可区分两种膜蛋白），不是电镜级结构，也不做细胞器百科
- 诊断对照在学生自己试过之后即可查看；若要课上更严，教师也可在面板里单独解锁「诊断标准示意」
- 未做账号、答题上传或成绩统计
